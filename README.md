
# Сұлулық салонына жазылу жүйесі

## 1. Жоба туралы

Бұл жобаның атауы — «Сұлулық салонына жазылу жүйесі».
Жобаның мақсаты — клиенттерге сұлулық салонының
қызметтерімен танысуға және қабылдауға жазылуға
мүмкіндік беретін веб-қосымша әзірлеу.

Жоба PHP, MySQL, HTML, CSS және JavaScript
технологияларын пайдалану арқылы жасалады.

## 2. Жобаның мақсаты

Сұлулық салонының жұмысын жеңілдету, клиенттерге
қызметтер туралы ақпарат беру және қабылдауға
жазылу процесін ыңғайлы ету.

## 3. Жобаның негізгі мүмкіндіктері

- Салонның басты бетін көру
- Сұлулық қызметтерінің тізімін қарау
- Қызметтердің бағасымен танысу
- Пайдаланушыны тіркеу және жүйеге кіру
- Қабылдауға жазылу
- Жазылу мәліметтерін көру
- Жазылуды өңдеу және жою
- Қызметтерді іздеу және сүзу
- Пайдаланушылардың деректерін қауіпсіз сақтау

## 4. Негізгі беттер

1. index.php — басты бет
2. services.php — қызметтер тізімі
3. booking.php — қабылдауға жазылу беті
4. register.php — тіркелу беті
5. login.php — жүйеге кіру беті
6. profile.php — пайдаланушы профилі
7. admin.php — әкімші басқару беті

## 5. Дерекқор құрылымы

Жобаның дерекқорында 5 негізгі кесте болады: USERS, SERVICES, BOOKINGS, PAYMENTS және EXPENSES. Бұл кестелер пайдаланушыларды, сұлулық қызметтерін, жазылуларды, төлемдерді және шығындарды есепке алу үшін қолданылады.

**1. USERS — пайдаланушылар**

Пайдаланушының ID нөмірі, толық аты-жөні, электрондық поштасы, құпиясөзінің хэші және рөлі сақталады. Рөлдер клиент пен әкімші болып бөлінеді.

**2. SERVICES — қызметтер**

Сұлулық салоны ұсынатын қызметтердің атауы, сипаттамасы, бағасы және ұзақтығы сақталады.

**3. BOOKINGS — жазылулар**

Клиенттің қай қызметке, қай күні және қай уақытта жазылғаны, сондай-ақ жазылудың мәртебесі сақталады. Бұл кесте USERS және SERVICES кестелерімен байланысады.

**4. PAYMENTS — төлемдер**

Клиент жасаған төлемнің сомасы, төлем күні, төлем әдісі және төлем мәртебесі сақталады. Бұл кесте BOOKINGS кестесімен байланысады. Әкімші нақты түскен кірісті есептей алады.

**5. EXPENSES — шығындар**

Салонның шығын сипаттамасы, сомасы, шығын күні, санаты және оны енгізген пайдаланушының ID нөмірі сақталады. Әкімші осы кесте арқылы салон шығындарын есепке алады.

**Кестелер арасындағы байланыс**

USERS кестесі BOOKINGS кестесімен байланысады, себебі әр жазылуды белгілі бір клиент жасайды. SERVICES кестесі BOOKINGS кестесімен байланысады, себебі әр жазылу нақты бір қызметке қатысты. BOOKINGS кестесі PAYMENTS кестесімен байланысады. USERS кестесі EXPENSES кестесімен байланысады, себебі шығынды енгізген пайдаланушы көрсетіледі.

**Кіріс пен шығысты есептеу**

Салонның жалпы кірісі сәтті төленген төлемдердің сомасы арқылы есептеледі. Жалпы шығыс EXPENSES кестесіндегі шығындар сомасын қосу арқылы анықталады. Қалған қаражатты есептеу үшін жалпы кірістен жалпы шығыс алынады.


## 6. Қолданылатын технологиялар

- HTML — веб-беттің құрылымы
- CSS — веб-беттің сыртқы көрінісі
- JavaScript — интерфейстің интерактивтілігі
- PHP — серверлік логика
- MySQL — дерекқорды басқару
- Git және GitHub — жобаның нұсқаларын сақтау

## 7. Қауіпсіздік

Пайдаланушы енгізген мәліметтер тексеріледі.
Құпиясөздер password_hash() арқылы хэштеледі.
Дерекқормен жұмыс істеу үшін PDO және
дайындалған SQL сұраныстары қолданылады.
Шығарылатын мәтіндер htmlspecialchars() арқылы
өңделеді.

## 8. Жобаның қазіргі жағдайы

Жобаның бастапқы кезеңінде басты беттің
интерфейсі жасалды. README құжаты дайындалуда.
Келесі кезеңдерде ER-диаграмма, дерекқор,
тіркелу, кіру және жазылуды басқару функциялары
іске асырылады.

## 9. Автор туралы

Жоба PHP және MySQL пәні бойынша жеке
жобалық тапсырма ретінде әзірленеді.
